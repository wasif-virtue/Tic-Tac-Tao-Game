# Tic-Tac-Toe

A two-player, turn-based Tic-Tac-Toe game for the browser, implemented with HTML, CSS, and vanilla JavaScript.

## Features

- Two players take turns as **O** and **X** on a 3 × 3 board
- Checks the eight winning combinations after each move
- Announces a winner or a draw
- Reset the current board or start a new round

## Run locally

There is no build step or dependency installation. Clone the repository and open `index.html` in a modern browser.

```bash
git clone https://github.com/wasif-virtue/Tic-Tac-Tao-Game.git
cd Tic-Tac-Tao-Game
```

## Project structure

| File | Purpose |
| --- | --- |
| `index.html` | Board markup and game status message |
| `style.css` | Board and page styling |
| `app.js` | Turn handling, win/draw checks, and reset actions |

This is a compact front-end project with no server-side code.
